What you are looking at

A two-spool high-bypass turbofan (default: CFM56-7B26, Boeing 737-800) simulated entirely in your browser. The server only delivered this page; nothing runs remotely.

Start the engine

  1. Press STARTER. N2 rises as the pneumatic starter motors the core.
  2. At about 25% N2, set the FUEL LEVER to RUN. Ignition fires, EGT rises after light-off.
  3. The starter cuts out at 56% N2; the engine stabilises at ground idle (N1 ≈ 21%, N2 ≈ 60%).

Commands: starter on|off, fuel on|off, tla x, alt m, mach x, isa dK, running tla (jump to a stabilised point), log on|off, speed x, note text, end.

Engine spec

Every number the model uses is in the JSON spec. Change the rated thrust, pressure ratios, efficiencies or limits, press Apply, and the design point is re-sized (nozzle areas and takeoff T4 are derived, not typed).

Model notes

Steady state is a station-by-station cycle with the turbine inlet temperature fixed by core-nozzle continuity. Transients use FADEC accel/decel schedules, spool inertia and sensor lags. Published ratings, speeds and limits are reproduced; proprietary component maps are replaced by calibrated power laws.
