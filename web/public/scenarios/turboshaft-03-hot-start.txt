# Hot start from an over-rich start schedule (fuel control mis-set, 1.6x):
# the fuel lights normally at ~15% N1, but with little airflow the TOT runs
# past the 927 C start limit. Procedure: throttle CUTOFF at once, keep the
# starter engaged to motor cool air through the turbine.
at 0    alt 0
at 0    fault start_fuel_factor 1.6
at 0    log on
at 0    ctl starter on
when ng >= 12   note Throttle IDLE: watch TOT
when ng >= 12   ctl throttle_twist 1
when tot >= 400  note Light-off. TOT rising fast on a slow-accelerating engine
when tot >= 927  note HOT START: throttle CUTOFF, keep motoring to cool
when tot >= 927  ctl throttle_twist 0
when tot >= 927  check tot >= 927
at 60   check tot < 600
at 60   check ng < 35
at 60   ctl starter off
at 69   check starter < 0.5
at 69   check ff < 0.001
at 70   end
